# Oil Money. Texas Power.

The public page for Future Heist's count of oil and gas money given to Greg Abbott, Dan Patrick and Ken Paxton, with the data files behind it in `data/`. Analysis by Saul Elbein.

This repository is generated: `index.html` and `data/` are written by `tools/build_site.py` in the analysis repository, so edits made here by hand are overwritten on the next build.
